# Library

- [`readiness.js`](readiness.js) owns safe template initialisation and structural project auditing.
- [`framework.js`](framework.js) validates this framework's required files, internal Markdown links, adoption-template placeholders, command-line entry point, and generic provenance leaks.

The library uses only Node.js standard modules. `init` must remain non-overwriting, and audit results must continue to state that structural checks do not prove control effectiveness.
