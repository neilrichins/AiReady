# WCAG 2.2 Level A and AA results matrix

Use this optional matrix with the [website](WEBSITE_ACCESSIBILITY_CHECKLIST.md)
or [mobile application](MOBILE_APPLICATION_ACCESSIBILITY_CHECKLIST.md)
checklist. It lists every Web Content Accessibility Guidelines (WCAG) 2.2 Level
A and AA success criterion. The linked [normative WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/)
controls if this summary differs from the standard.

For non-web software, record the adopted legal or contractual standard and use
the relevant interpretation in [Guidance on Applying WCAG 2 to Non-Web
Information and Communications Technologies (WCAG2ICT)](https://www.w3.org/TR/wcag2ict-22/).
WCAG2ICT is informative and does not create a native-software conformance claim
or replace additional platform, software, procurement, or legal requirements.
