# AI Ready documents

This directory contains the complete documentation framework. Its structure is a catalogue for this repository only; it does not prescribe how an adopting project organises its files or systems.

## Start here

1. Read the [adoption guidance](guidance/adoption.md).
2. Complete the [AI coding readiness assessment](AiReady.md) against current evidence.
3. Use the [adoption map](boilerplate/ADOPTION_MAP.md) to identify where each concern already lives in the project.
4. Select and adapt only the [boilerplate documents](boilerplate/README.md) needed to close genuine gaps.
5. Keep existing authoritative records where they work; do not create duplicate sources of truth.

## Boilerplate themes

- project definition, requirements, roadmap, status, and features;
- AI-agent authority and contribution controls;
- architecture and interconnected repository/component coordination;
- traceability, testing, verification, risks, and decisions;
- release process, checklist, readiness, evidence, operations, and recovery; and
- security and change review.
