# Framework documentation

- [`methodology.md`](methodology.md) defines the evidence model, scoring, blockers, and assessment limitations.
- [`adoption.md`](adoption.md) provides a staged route from unstructured AI assistance to controlled automation.
- [`control-catalogue.md`](control-catalogue.md) maps each control area to expected evidence and common failure modes.

The canonical project assessment remains [`../AiReady.md`](../AiReady.md). Changes to scoring or readiness levels must update all affected documents, templates, tests, and command-line output together.
