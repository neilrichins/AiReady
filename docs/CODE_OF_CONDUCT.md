# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

## Our standards

Positive behaviour includes empathy, respectful disagreement, constructive feedback, accountability, and attention to the effect of words and actions. Unacceptable behaviour includes harassment, discrimination, threats, sexualised attention, deliberate intimidation, publication of private information, and sustained disruption.

## Scope

This Code applies in repository issues, pull requests, reviews, discussions, and other public or private project interactions. It also applies when someone officially represents the project.

## Enforcement

Report conduct concerns privately to the repository owner through the contact method listed on their GitHub profile. Include relevant links or context while minimising personal and sensitive information. If a concern involves the repository owner or cannot be reported safely through that route, use [GitHub's content-reporting process](https://docs.github.com/en/site-policy/content-removal-policies/guide-to-submitting-a-report-of-abuse).

Maintainers will review reports as promptly and impartially as practical, protect reporter privacy to the extent possible, and document proportionate action. Maintainers may correct or remove content, request changed behaviour, issue a warning, reject contributions, or temporarily or permanently restrict participation. Retaliation against a reporter or participant in an investigation is prohibited.
