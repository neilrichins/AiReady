# Contributing

## Before starting

1. Create or select an issue.
2. Define the problem, outcome, acceptance criteria, constraints, and evidence required.
3. Read `AGENTS.md` and the README for each affected directory.

## Development

- Supported runtime/toolchain: `{{VERSIONS}}`.
- Clean installation command: `{{COMMAND}}`.
- Complete quality command: `{{COMMAND}}`.
- Preserve source ownership and generated-file boundaries.
- Add tests for behaviour and safety changes.
- Update documentation with interface, architecture, command, or operational changes.

## Review

Pull requests require `{{NUMBER}}` reviewer(s), passing required CI, resolved security findings, and recorded manual checks where applicable. AI-generated changes receive the same or greater review as human-written changes.
